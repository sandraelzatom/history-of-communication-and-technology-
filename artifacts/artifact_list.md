# Museum Artifacts & Sources

### 1. The Morse-Vail Telegraph Key (Primary Source)
* **Link:** [Smithsonian Institution - Morse Telegraph](https://www.si.edu/object/morse-vail-telegraph-key:nmah_1096530)
* **Description:** An original 1844 telegraph key used to send the first long-distance message.
* **Significance:** It represents the beginning of real-time long-distance communication.

### 2. Bell’s First Telephone Patent (Historical Document)
* **Link:** [National Archives - Alexander Graham Bell Patent](https://catalog.archives.gov/id/302052)
* **Description:** The official 1876 patent for the telephone.
* **Significance:** This marks the shift from coded pulses (Morse) to the transmission of the human voice.

### 3. Transatlantic Telegraph Cable (Historical Context)
* **Link:** [Wikipedia - Transatlantic Telegraph Cable](https://en.wikipedia.org/wiki/Transatlantic_telegraph_cable)
* **Description:** An overview of the first undersea cable connecting Europe and North America.
* **Significance:** It shows the massive physical infrastructure required to connect the world globally.

### 4. Motorola "Brick Phone" (Product Media)
* **Link:** [Motorola DynaTAC 8000X Promo](https://www.motorola.com/blog/post?id=the-evolution-of-the-mobile-phone)
* **Description:** The first commercially available handheld cellular phone.
* **Significance:** It illustrates the transition from "place-to-place" communication to "person-to-person" communication.
